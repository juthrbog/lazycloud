# S3

Browse, preview, download, copy, move, and manage S3 buckets and objects.

## Views

### Bucket List

Lists all S3 buckets accessible to the current profile/credentials.

| Column | Description |
|--------|-------------|
| Bucket | Bucket name |
| Created | Creation date |

### Object Browser

Browse objects within a bucket with folder-style navigation using S3 prefixes. Objects load progressively (1000 per page) so the first results appear immediately.

| Column | Description |
|--------|-------------|
| Type | Folder or file icon |
| Name | Object key (relative to current prefix) |
| Size | Human-readable file size |
| Modified | Last modified date |
| Class | Storage class (STANDARD, GLACIER, etc.) |

### Version List

View all versions of a specific object (requires versioning enabled on the bucket). The list shows every version and delete marker of the object, also when there are more than 1,000. Versions of other keys that start with the same text, for example `report.pdf.bak`, do not show.

| Column | Description |
|--------|-------------|
| Version ID | S3 version identifier |
| Size | Version size |
| Modified | Version timestamp |
| Latest | Whether this is the current version |
| Delete Marker | Whether this is a delete marker |

## Content Preview

Pressing `enter` on a file performs a HEAD check to determine if the file is previewable:

- **Text files** (by ContentType or extension): content is fetched (up to 1MB) and displayed with syntax highlighting in the content viewer
- **Binary or large files**: object metadata is shown as a fallback

Supported text extensions: `.txt`, `.json`, `.yaml`, `.yml`, `.xml`, `.html`, `.css`, `.js`, `.ts`, `.go`, `.py`, `.sh`, `.md`, `.csv`, `.log`, `.conf`, `.toml`, `.tf`, `.hcl`, `.sql`, and more.

A file or a key can hold terminal control characters, for example in a log line that came from a user. A terminal acts on these characters, so LazyCloud shows each one as a visible symbol: ESC as `␛`, a carriage return as `␍`, and a C1 control character as `�`. The same applies to tags, message bodies, and the other text from AWS. The `y` (yank) and `e` (editor) keys of the preview use the original text.

## Multi-Select

Press `space` to select or deselect an item. A selected item shows a `✓` marker, and the status bar shows the selection count. Press `x` to delete the selected items. The prompt lists them, and you type "confirm" to delete them.

Press `X` to delete every item that the list shows, without a selection. The prompt lists them, and you type `delete N items`, for example `delete 12 items`.

The filter deselects the items that it hides, so a delete never includes an item that you cannot see. When a filter is on, `X` deletes only the items that the filter shows. A selection stays on the same item when a new page loads or when you sort the list.

S3 can refuse to delete some keys, for example because of a bucket policy or Object Lock. Then the list loads again, because S3 deleted the other keys. The toast says how many objects S3 deleted and names the failed keys with their AWS error codes. The event log has the full error of each key.

## Copy and Move

Press `c` to copy the object under the cursor, or `m` to move it. Type the destination and press `enter`. The destination is in the same bucket:

- A key from the bucket root, for example `archive/2026/report.pdf`, is the new key of the object.
- A key that ends with `/`, for example `archive/`, is a folder. The object keeps its name in that folder: `archive/report.pdf`.
- An empty destination gives `<key>_copy` next to the source.

LazyCloud refuses a destination that is the source object.

If an object exists at the destination, LazyCloud asks before it replaces that object. You type "confirm" to replace it. If you cancel, nothing is copied, and a move keeps the source. S3 also refuses the copy if another program creates the destination after LazyCloud looked for it.

The copy keeps the storage class, the metadata, and the content headers of the source. Keys with spaces or characters such as `%`, `+`, or `?` copy correctly.

S3 copies an object of up to 5 GB in one request. A larger object is copied in parts of 512 MB or more (a multipart copy). A multipart copy does not copy the tags of the object. If a part fails, LazyCloud stops the upload, so no incomplete parts stay in the bucket.

A move is a copy followed by a delete of the source. If the delete fails, both objects stay, and the error shows.

## Download

Press `w` to download the object under the cursor to `~/Downloads/`. The file gets the last part of the key as its name.

LazyCloud never replaces a file. If `report.pdf` exists, the download goes to `report (1).pdf`, then to `report (2).pdf`, and so on. The toast shows the path that LazyCloud wrote.

Only you can read the downloaded file (mode 0600). If the download fails, LazyCloud removes the partial file. A download has no progress bar and cannot be canceled yet.

## Bucket Operations

- **Create** (`n`): enter a bucket name, creates in the current region
- **Properties** (`d`): shows versioning status, encryption, public access block, and region
- **Delete** (`x`): deletes the selected buckets, or the bucket under the cursor. Every object version and delete marker is deleted permanently, then the bucket. For one bucket, you type the bucket name to confirm. For several buckets, the prompt lists them, and you type `delete N buckets`, for example `delete 2 buckets`. Each bucket is tried, also after one fails. Then the list loads again, and the toast names the failed buckets with their AWS error codes. A failed bucket can be partly empty.

## Cross-Region Support

Buckets are automatically accessed in their correct region. LazyCloud resolves each bucket's region via `GetBucketLocation` to avoid 301 redirect errors when the bucket is in a different region than the configured client.

## Service Layer

`internal/aws/s3.go` implements the `S3Service` interface:

```go
type S3Service interface {
    ListBuckets(ctx context.Context) ([]Bucket, error)
    ListObjectsPage(ctx context.Context, bucket, prefix string, token *string) (*ObjectPage, error)
    HeadObject(ctx context.Context, bucket, key string) (*ObjectMeta, error)
    GetObjectContent(ctx context.Context, bucket, key string, maxBytes int64) (string, error)
    PresignGetObject(ctx context.Context, bucket, key string, expiry time.Duration) (string, error)
    ListAllKeys(ctx context.Context, bucket, prefix string) ([]string, error)
    DownloadObject(ctx context.Context, bucket, key, destPath string) (string, error)
    ListObjectVersions(ctx context.Context, bucket, key string) ([]ObjectVersion, error)
    GetBucketProperties(ctx context.Context, bucket string) (*BucketProperties, error)
    GetBucketRegion(ctx context.Context, bucket string) (string, error)
    DeleteObject(ctx context.Context, bucket, key string) error
    DeleteObjects(ctx context.Context, bucket string, keys []string) error
    DeleteObjectVersions(ctx context.Context, bucket string, versions []ObjectVersion) error
    DeleteBucket(ctx context.Context, bucket string) error
    EmptyAndDeleteBucket(ctx context.Context, bucket string) error
    CopyObject(ctx context.Context, srcBucket, srcKey, dstBucket, dstKey string, overwrite bool) error
    MoveObject(ctx context.Context, srcBucket, srcKey, dstBucket, dstKey string, overwrite bool) error
    CreateBucket(ctx context.Context, name, region string) error
}
```

`DownloadObject` returns the path that it wrote. `DeleteObjects` returns a `*DeleteObjectsError` that lists the keys S3 did not delete. `CopyObject` and `MoveObject` return `ErrDestinationExists` when the destination exists and `overwrite` is false.

Object listing uses paginated fetching (`ListObjectsPage`) with progressive loading. Buckets are automatically accessed in their correct region via `GetBucketRegion`. A shared `MockS3Service` in `internal/aws/awstest/` enables testing views without AWS credentials.

```bash
task localstack:seed
```
